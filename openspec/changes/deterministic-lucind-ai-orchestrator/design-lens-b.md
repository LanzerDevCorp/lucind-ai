# Design Lens B — Surface & Flow: Deterministic lucind-ai Orchestrator

## Assumed architecture

A two-layer deterministic contract separates the canonical Claude prompt state machine in `plugin/claude-code/skills/lucind-ai/` (with a byte-identical copy in `plugin/opencode/skills/lucind-ai/`) from machine-enforced Go runtime invariants. Packages `internal/packet`, `internal/dag`, `internal/run`, `internal/ledger`, `internal/worktree`, `internal/result`, and `cmd/lucind-ai` are extended for fail-closed preflight, late target binding, open-scope defaults, and idempotent retry. A dedicated `internal/accept` package consolidates frozen evidence acceptance verification (candidate commits, tree hashes, schema-valid envelopes, clean worktrees) before CAS promotion. No new lifecycle states, schedulers, flags, or routing mechanisms are introduced.

## Flow and Invariants

```
[1. Preflight & Parity] ──→ [2. Packet Late Binding] ──→ [3. DAG Split & Waves]
                                                                  │
[6. CAS Promotion / Recovery] ←── [5. Combine & Check] ←── [4. Barrier & Accept]
```

1. **Preflight & Parity Check** (`cmd/lucind-ai` ──→ `plugin/`):
   - *Invariant*: Claude skill (`plugin/claude-code/skills/lucind-ai/`) and OpenCode copy (`plugin/opencode/skills/lucind-ai/`) are byte-identical; primary root is clean and not linked ([internal/worktree/worktree.go:278-292](file:///home/lanzerdev/git_root/lucind-ai-deterministic-orchestrator-worktrees/design-deterministic-lucind-ai-orchestrator-lens-b/internal/worktree/worktree.go#L278-L292)); binary schemas match.
   - *Breaks*: Stale prompts or schemas execute; sibling worktrees collide.

2. **Packet Admission & Late Binding** (`internal/packet` ──→ `internal/run`):
   - *Invariant*: Target-free templates ([internal/packet/packet.go:63-72](file:///home/lanzerdev/git_root/lucind-ai-deterministic-orchestrator-worktrees/design-deterministic-lucind-ai-orchestrator-lens-b/internal/packet/packet.go#L63-L72)) bind targets dynamically at dispatch; omitted `allowed_paths` defaults to open scope (`len(AllowedPaths) == 0`, [internal/packet/disjoint.go:29-33](file:///home/lanzerdev/git_root/lucind-ai-deterministic-orchestrator-worktrees/design-deterministic-lucind-ai-orchestrator-lens-b/internal/packet/disjoint.go#L29-L33)); malformed frontmatter yields `ErrInvalidAllowedPaths` ([internal/packet/packet.go:29](file:///home/lanzerdev/git_root/lucind-ai-deterministic-orchestrator-worktrees/design-deterministic-lucind-ai-orchestrator-lens-b/internal/packet/packet.go#L29)).
   - *Breaks*: Templates fail admission or branch from wrong base; orphan worktrees are created.

3. **DAG Split & Wave Planning** (`internal/dag` ──→ `stdout`):
   - *Invariant*: `dag.Parse` ([internal/dag/parse.go:40-43](file:///home/lanzerdev/git_root/lucind-ai-deterministic-orchestrator-worktrees/design-deterministic-lucind-ai-orchestrator-lens-b/internal/dag/parse.go#L40-L43)) parses `apply-dag.yaml`; `dag.Waves` ([internal/dag/waves.go:16-73](file:///home/lanzerdev/git_root/lucind-ai-deterministic-orchestrator-worktrees/design-deterministic-lucind-ai-orchestrator-lens-b/internal/dag/waves.go#L16-L73)) orders waves and verifies reachability overlap via `dag.ValidateGlobalOverlap` ([internal/dag/overlap.go:54-79](file:///home/lanzerdev/git_root/lucind-ai-deterministic-orchestrator-worktrees/design-deterministic-lucind-ai-orchestrator-lens-b/internal/dag/overlap.go#L54-L79)); `dag.Split` ([internal/dag/split.go:18-46](file:///home/lanzerdev/git_root/lucind-ai-deterministic-orchestrator-worktrees/design-deterministic-lucind-ai-orchestrator-lens-b/internal/dag/split.go#L18-L46)) writes packets under `--out` and emits sequential `lucind-ai run` commands to stdout without plan files.
   - *Breaks*: Unordered concurrent lanes collide on shared paths; plan files dirty the working tree.

4. **Concurrent Execution & Barrier** (`internal/run` ──→ `internal/barrier`):
   - *Invariant*: Lanes execute in isolated worktrees ([internal/worktree/worktree.go:173-177](file:///home/lanzerdev/git_root/lucind-ai-deterministic-orchestrator-worktrees/design-deterministic-lucind-ai-orchestrator-lens-b/internal/worktree/worktree.go#L173-L177)); `barrier.Evaluate` ([internal/barrier/barrier.go:36-60](file:///home/lanzerdev/git_root/lucind-ai-deterministic-orchestrator-worktrees/design-deterministic-lucind-ai-orchestrator-lens-b/internal/barrier/barrier.go#L36-L60)) joins when all lanes reach terminal status ([internal/lane/status.go:21-28](file:///home/lanzerdev/git_root/lucind-ai-deterministic-orchestrator-worktrees/design-deterministic-lucind-ai-orchestrator-lens-b/internal/lane/status.go#L21-L28)); failures do not cancel siblings.
   - *Breaks*: Barrier blocks on unobserved lanes; sibling failures discard diagnostics.

5. **Acceptance Verification** (`internal/accept` ──→ `internal/ledger`):
   - *Invariant*: Lanes are verified against candidate commits, clean porcelain ([internal/worktree/worktree.go:319-325](file:///home/lanzerdev/git_root/lucind-ai-deterministic-orchestrator-worktrees/design-deterministic-lucind-ai-orchestrator-lens-b/internal/worktree/worktree.go#L319-L325)), and valid `.lucind/result.json` ([internal/result/result.go:141-162](file:///home/lanzerdev/git_root/lucind-ai-deterministic-orchestrator-worktrees/design-deterministic-lucind-ai-orchestrator-lens-b/internal/result/result.go#L141-L162)); `read_only: true` requires zero commits ([internal/worktree/worktree.go:297-315](file:///home/lanzerdev/git_root/lucind-ai-deterministic-orchestrator-worktrees/design-deterministic-lucind-ai-orchestrator-lens-b/internal/worktree/worktree.go#L297-L315)); fired hard stops ([internal/result/result.go:30-34](file:///home/lanzerdev/git_root/lucind-ai-deterministic-orchestrator-worktrees/design-deterministic-lucind-ai-orchestrator-lens-b/internal/result/result.go#L30-L34)) or undeclared path diffs demote status to `lane.Blocked` or `lane.Deviated`.
   - *Breaks*: Fired hard stops or undeclared diffs are falsely marked `done`.

6. **Combine, Checks, CAS Promotion & Retry** (`internal/integrate` ──→ `internal/run`):
   - *Invariant*: `integrate.Combine` ([internal/integrate/integrate.go:45-47](file:///home/lanzerdev/git_root/lucind-ai-deterministic-orchestrator-worktrees/design-deterministic-lucind-ai-orchestrator-lens-b/internal/integrate/integrate.go#L45-L47)) merges `done` lanes; `integrate.Check` runs checks; `integrate.PromoteCAS` updates `parent_ref` only on matching expected SHA; retry ([internal/run/attempt.go:66-77](file:///home/lanzerdev/git_root/lucind-ai-deterministic-orchestrator-worktrees/design-deterministic-lucind-ai-orchestrator-lens-b/internal/run/attempt.go#L66-L77)) returns recorded results without re-dispatch; recovery verifies recorded refs, failing closed on mismatch while preserving worktrees and ledger rows.
   - *Breaks*: Stale parent ref overwrites commits; retries re-dispatch lanes; recovery deletes diagnostic evidence.
