## Rollback & Additivity

**Rollback Plan**: Reversion requires a standard `git revert` of commits in `internal/ledger/`, `internal/serve/`, and `cmd/lucind-ai/`. Database schema version advancement from 5 ([internal/ledger/schema.go:10](file:///home/lanzerdev/git_root/lucind-ai-worktrees/propose-control-room-ledger-lens-c/internal/ledger/schema.go#L10)) to 6 is backward-compatible; v5 binaries continue operating against existing tables (`lanes`, `events`, `approvals`, `features`, `feature_leases`) on a v6 database without error, as SQLite ignores unused tables and nullable columns. No destructive schema downgrade script is required.

**Additivity**: All database, wire, and Go API changes are strictly additive:
- **Database Schema**: New tables `runs` and `lane_progress` add storage without modifying existing table semantics ([internal/ledger/schema.go:18-57](file:///home/lanzerdev/git_root/lucind-ai-worktrees/propose-control-room-ledger-lens-c/internal/ledger/schema.go#L18-L57)). Rebuilding `lanes` via copy-drop-rename ([internal/ledger/schema.go:191-219](file:///home/lanzerdev/git_root/lucind-ai-worktrees/propose-control-room-ledger-lens-c/internal/ledger/schema.go#L191-L219)) adds nullable columns `model`, `agent`, and `feature` defaulting to empty/null while preserving all v5 columns. Rebuilding `events` ([internal/ledger/schema.go:59-78](file:///home/lanzerdev/git_root/lucind-ai-worktrees/propose-control-room-ledger-lens-c/internal/ledger/schema.go#L59-L78)) widens `type` CHECK literals to admit `run_status_changed` while retaining existing types ([internal/ledger/schema.go:38-39](file:///home/lanzerdev/git_root/lucind-ai-worktrees/propose-control-room-ledger-lens-c/internal/ledger/schema.go#L38-L39)).
- **Query Surface & DTOs**: `serve.Model` introduces new read DTOs (`Run`, `ProgressChunk`) without altering existing feature/lease structs ([internal/serve/model.go:14-25](file:///home/lanzerdev/git_root/lucind-ai-worktrees/propose-control-room-ledger-lens-c/internal/serve/model.go#L14-L25)).
- **Result & Packet Schemas**: Packet parsing ([internal/packet/packet.go:33-75](file:///home/lanzerdev/git_root/lucind-ai-worktrees/propose-control-room-ledger-lens-c/internal/packet/packet.go#L33-L75)) and result envelope schema ([.lucind/result.schema.json:1-160](file:///home/lanzerdev/git_root/lucind-ai-worktrees/propose-control-room-ledger-lens-c/.lucind/result.schema.json#L1-L160)) remain unchanged.
