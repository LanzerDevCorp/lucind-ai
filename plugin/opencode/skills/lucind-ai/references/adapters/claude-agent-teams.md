# Claude Agent Teams adapter

Load this module only when evaluating Claude Agent Teams as a Collaboration Channel.

Agent Teams is deferred and optional. It is not a current stable-core dependency, and `lucind-ai` cannot launch or manage an Agent Team today.

If adopted later, treat it only as a provider-specific, temporary Agent-to-Agent Collaboration Channel inside one Change. Git, packet/result evidence, the ledger, Shared Memory, Dependencies, Acceptance, and Promotion remain vendor-neutral authority. Team messages are not durable coordination state and cannot transfer Orchestrator ownership or alter an Execution Route.

Do not route current packets through an imagined adapter, claim Team membership in runtime status, or make stable behavior depend on provider-private conversation history.
