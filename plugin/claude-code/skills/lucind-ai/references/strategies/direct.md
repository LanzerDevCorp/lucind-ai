# Direct strategy

Load this module when the human approved direct completion by the Change's Orchestrator.

## Execution

1. Work only inside the Change Write Scope in its selected Mode.
2. Do not create Lanes, packets, executor routes, SDD artifacts, or fan-out merely because `lucind-ai` is available.
3. Run the repository's focused checks, inspect the diff, and verify terminal consumers and scope.
4. Record evidence and request human confirmation before Promotion.

Direct work changes the execution method, not Change identity or safety obligations. If delegation becomes necessary, stop and obtain approval for the new Execution Strategy before loading packet or fan-out modules.
